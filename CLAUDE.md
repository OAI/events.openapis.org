# This repo is for publishing, not planning

events.openapis.org only publishes events and programs that are **confirmed**.
It is not where event planning happens.

- Do **not** add tentative or candidate speakers, draft programs, CFP picks,
  placeholder talks, or "maybe" sessions here. An event's `speakers:` list and
  agenda are public as soon as they are merged.
- Planning, candidate tracking, and program drafting happen elsewhere (for the
  OpenAPI Initiative tracks, in the OAI-Tracks repo). Content moves here only
  once it is final.
- Upcoming events may exist here as minimal entries (title, dates, location,
  description, no speakers) so the event can be announced.
- Cancellations and speaker swaps are made at the source first, then mirrored
  here.
- Never bake planning notes, TODOs, or unconfirmed names into `event.yaml`,
  `speakers.yaml`, or the descriptions.

When in doubt: if it isn't confirmed and ready for the public, it doesn't
belong in this repo.
